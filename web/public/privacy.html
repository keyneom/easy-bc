EasyBC privacy policy

Effective June 21, 2026

EasyBC is local-first. It has no EasyBC account server, advertising SDK, or analytics SDK.

Data stored locally

Period records, day logs, body-signal observations, planner settings, and generated plans stay in application or browser storage. Android platform backup is disabled.

Optional encrypted sync

When explicitly enabled in the web app, EasyBC uses Google Drive's non-sensitive drive.file scope. Each owner gets a visible Drive folder named with their Google account email (for example EasyBC — you@example.com). EasyBC encrypts reproductive-health records on the device before upload; Drive stores ciphertext. Owners can invite others by email with viewer or writer access. Folder names, file metadata, and participant lists are visible in Google Drive to people with folder access.

Android uses the same shared-folder model with a per-device sharing identity stored in EncryptedSharedPreferences (Android Keystore). Raw passkey output and derived keys are kept only in memory for the active session. A short-lived Google access token may remain in tab or app-process memory for automatic sync, but is not intentionally written to browser or app storage and is cleared when the session ends or after 15 minutes in the background.

EasyBC uses Google user data only to provide encrypted sync requested by the user and does not sell or transfer that data to third parties.

User-directed exports

Manual JSON backups, iCalendar exports, and entries written to a device calendar are not encrypted by EasyBC. Treat them as sensitive files.

Retention and deletion

Local data remains until records or application storage are deleted. Encrypted web sync data remains in the owner's Google Drive folder until the user removes encrypted sync from EasyBC or deletes the folder in Google Drive. Legacy Android app-data snapshots remain until deleted through EasyBC settings or Google Account app-data cleanup. Revoking OAuth access prevents future access but does not by itself guarantee file deletion.

Security reports

Use the repository's private security advisory form. Do not post personal health data in public issues.
